# Shijas Cherakkatil | Portfolio

Personal portfolio site built with React, Vite and Tailwind CSS. Deployed at https://shijas.netlify.app/.

## Run locally

**Prerequisites:** Node.js 20+

```sh
npm install
npm run dev      # http://localhost:3000
npm run build    # production build in dist/
npm run lint     # type-check
```

Site content (projects, experience, skills, publications) lives in `constants.ts`.
